## Повторение

Нужны Python 3.12 и RustFS на порту 9000. Использован четырёхдисковый стенд
лабораторной 2, EC 2+2. Новый стенд можно создать по
[инструкции RustFS](https://docs.rustfs.com/en/installation/windows).
Задать `RUSTFS_ACCESS_KEY`, `RUSTFS_SECRET_KEY`, при необходимости `RUSTFS_ENDPOINT_URL`.
На исходном компьютере ключи также читаются из `../lab/.credentials.json`.
Ключи не выводятся в журнал и не входят в Git.

Скачать CSV и hh.zip по ссылкам выше в `data/`, сохранив их имена.
Затем выполнить из папки работы:

```powershell
python -m pip install --target ./python-packages -r requirements.txt
./Run-Lab.ps1 check
./Run-Lab.ps1 init-storage
./Run-Lab.ps1 setup-duckdb
./Run-Lab.ps1 audit
./Run-Lab.ps1 upload
./Run-Lab.ps1 benchmark
./Run-Lab.ps1 fault
./Run-Lab.ps1 verify
./Run-Lab.ps1 analyze
./Run-Lab.ps1 test
```

## Подсчёт

Навыки разделяются по `;`, очищаются от пробелов по краям и приводятся к нижнему регистру.
Повторы внутри вакансии удаляются. Сочетания неупорядоченные, без повторения навыка.
Вакансия с n навыками даёт C(n,k) сочетаний размера k.

MapReduce читает S3 порциями по 1 МиБ, обрабатывает батчи по 1 000 строк четырьмя процессами.
Базовая версия материализует промежуточные пары «ключ–1». Оптимизированная передаёт
мапперам только нужные столбцы и применяет локальный combiner.
DuckDB независимо фильтрует тот же объект через httpfs и строит сочетания на SQL.
Сравниваются все ключи, частоты и SHA-256 отсортированного списка выбранных вакансий.
Таблицы для k=1,2,3 записываются в `results/variant-01/{mapreduce,duckdb}/` в S3
и проверяются обратным чтением.

В тесте отказа процесс маппера завершается с кодом 73. Новый pool повторяет только
незафиксированные батчи; итог сравнивается с обычным запуском.

## Профилирование и анализ

Каждый способ запускается трижды отдельным процессом; порядок между сериями меняется.
Время включает запуск, чтение из S3, расчёт и запись результатов.
Память — максимальная измеренная сумма RSS процесса и его дочерних процессов.
Между опросами монитор делает паузу 5 мс; сами опросы также занимают время.
Сервер и монитор в RSS клиента не входят. httpfs установлен заранее. Кеш ОС не очищается.

Для медиан используются рублёвые зарплаты с gross=false: среднее двух границ
или единственная указанная граница. В частотах учитываются и вакансии без зарплаты.
В рейтинги входят сочетания с минимум 20 зарплатными наблюдениями.
База пары — более частый навык, база тройки — самая частая входящая пара;
частоты базы определяются по всему сегменту, при равенстве — алфавитный порядок.
Разница медиан описывает объявления, а не причинный эффект добавленного навыка.

Три региона выбираются по числу вакансий варианта. Знаменатель долей навыков —
все вакансии региона, включая объявления без навыков.
